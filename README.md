
# Suspicious Message Analyzer

## Project Overview
A beginner-friendly cybersecurity awareness project that checks
messages for common phishing warning signs.

## Technologies Used
- HTML
- CSS
- JavaScript
- Visual Studio Code

## Features
- Message input and optional sender field
- Detection of common suspicious phrases
- Simple warning score from 0 to 100
- Warning signs and recommended actions
- Safety guidance for users who entered credentials
- Responsive design
- No external API required

## How to Run
1. Download and install Visual Studio Code.
2. Create the Task21_Suspicious_Message folder.
3. Create index.html, style.css, script.js and README.md.
4. Paste the corresponding code into each file.
5. Open index.html in a browser, or use the Live Server extension.

## Test Message
URGENT: Your account will be suspended today.

## Limitations
This project uses simple phrase matching. It does not verify
sender identity, email headers, domain reputation or website safety.
Its warning score is not a probability or a definitive verdict.

## Purpose
To help users recognize potential phishing messages and practice
safer cybersecurity decisions.
